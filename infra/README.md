# Infraestructura como código

> Se construye en la **fase 1**. Por ahora esta carpeta solo reserva su lugar en la estructura del proyecto.

Todo lo que se configura en los servidores Windows, en scripts versionados: powershell/ (servicios, firewall, backups, despliegue), iis/ (web.config), cloudflare/ (túnel), vpn/ (plantillas de WireGuard, nunca llaves) y observability/ (Loki, Grafana, Uptime Kuma). Se llena desde la fase 1.
