## [0.1.0] · Fase 0

### Agregado

- Estructura del monorepo con workspace de uv.
- Paquete `melomap-ingest` con carga y validación tipada de `config/countries.yaml`.
- Comando `melomap-countries`.
- Tests con pytest y cobertura mínima de 90 %.
- Ruff, mypy en modo estricto y pre-commit con gitleaks.
- Workflow de CI en GitHub Actions sobre Windows.
- Dependabot para acciones y dependencias.
- Documentación inicial: README, guía de la fase 0, ADR 0001, identidad visual.
